## 安全架构

V11 形成 **"安全可信、内生双体系架构"**，核心组件：

| 组件 | 职责 |
|------|------|
| **KySEC** | 麒麟自研内核级强制访问控制（MAC） |
| **SELinux** | Linux 标准 MAC，strict 模式下启用 |
| **KSAF** | 可编程安全框架（V11 首创） |
| **三权分立** | strict 模式下 root/secadm/auditadm 分权 |

### KSAF 可编程安全框架

KSAF（Kylin Security & Access control Framework）核心思想：**安全机制与安全策略分离**。

三层架构：安全交互层 → 安全定义层 → 安全语言层

区别于传统 LSM+SELinux 的策略-机制绑定：
- 无需修改内核代码
- 无需重新编译
- 可在部署后/运行时动态定制安全策略
- 实现"安全即代码"
